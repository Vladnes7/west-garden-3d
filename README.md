# West Garden · 43 м² — 3D-прогулка

Интерактивная 3D-модель квартиры 103 (ЖК West Garden, пр-т Генерала Дорохова 39 к2) по рабочей документации и визуализациям дизайнера.

- Геометрия стен снята с плана монтажа (лист 7) и откалибрована по размерам: площадь 43,24 м² против 43,33 м² в экспликации.
- Высоты: потолок ГКЛ1 2,87 м, ГКЛ2 2,77 м (прихожая, кухонная ниша, санузел), скрытые двери 2,77 м, подоконники 0,49/0,51 м.
- Открываются шкафы, ящики, холодильник, двери и дверь душа; панель «Отделка» меняет цвета и материалы.
- Режимы: прогулка (WASD/мышь, джойстик на телефоне), обзор сверху с кнопками комнат, день/вечер/ночь.

Запуск: `npm run dev` → http://localhost:8794. Сборка в один офлайн-файл: `npm run build`.
